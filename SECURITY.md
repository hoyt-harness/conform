# Security Policy

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue, please
report it by following these steps:

1. Navigate to the main page of this repository on GitHub.
2. Click the **Security** tab.
3. Click **Report a vulnerability** to open the advisory form.
4. Fill in the form with as much detail as possible.

We will respond within 48 hours.

## Security Standards

This project follows the
[Positronikal Repository Security Rules](https://github.com/Positronikal/PositronikalCodingStandards/blob/main/standards/Repository%20Security%20Rules.md).

## Disclosure Policy

- **Initial response**: within 48 hours of report
- **Severity assessment**: within 72 hours
- **Patch development**: critical issues within 7 days; others within 30 days
- **Public disclosure**: after patch is available

We practice responsible disclosure. Please allow reasonable time for patching before
public disclosure and avoid exploiting vulnerabilities beyond proof-of-concept.
